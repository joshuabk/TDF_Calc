Model

BEDnormal = N · d · (1 + d / (α/β)) − K · T

Eq. (A): N = number of well-spaced fractions, d = dose per fraction (Gy).

BEDtumor = N · d · (1 + d / (α/β)) − K · (T − Tk)   for T ≥ Tk

Eq. (B): T = overall treatment time, Tk = lag before rapid repopulation, K = daily BED-equivalent of repopulation.
