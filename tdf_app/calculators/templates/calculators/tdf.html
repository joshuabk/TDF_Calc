Model

TDF = N · d1.538 · (T / N)−0.169 · 10−3

d = dose per fraction in cGy (doses are entered in Gy and converted), N = number of fractions, T = elapsed days.

TDFARP = TDF1 · (T1 / (T1 + R))0.11

T1 = days from first fraction to start of rest, R = rest period (days).

N2 = (103 · TDF2 · T20.169 / d1.538)1/1.169;  fractions to add = N2 − (N − N1)
